# Анимация пенальти в футболе с помощью Java Swing

1. Интерфейсы `Drawable` и `Animatable` для рисования и анимации объектов.
2. Классы `Circle`, `Rectangle`, `Line`, `Pentagon`, `RoundedRectangle`, `Triangle` для представления графических примитивов.
3. Отрисовка мяча в классе `Ball`, используя примитивы `Pentagon`, `Circle`.
4. Отрисовка ворот в классе `Gates`, используя примитивы `Triangle`, `Line`.
5. Отрисовка поля в классе `Field`, используя примитивы `Rectangle`, `Line`.
6. Отрисовка игрока в классе `Human`, используя примитивы `Circle`, `Line`.
7. Отрисовка табла счета в классе `Score`, используя примитивы `Rectangle`. Создан внутренний класс `Digit` для отрисовки цифр используя примитивы `Line`.
8. Отрисовка трибуны в классе `Tribune`, используя примитивы `RoundedRectangle`, `Line`, `Rectangle`.
9. Создание сцены анимации создается в классе `GuiAnimateFrame`, панель для отрисовки - `DrawingPanel`.
10. В `GuiAnimateFrame` реализована логика обработки удара по пробелу и анимации пенальти (путем вызова методов объектов мяча и игрока), а также обновление счета.
